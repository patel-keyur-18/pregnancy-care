# pregnancy-care

A calm, privacy-first pregnancy care app for iOS and Android. It combines Garbhasanskar practice (reading, mantra and music sessions), low-screen habits, care tracking (supplements, vaccines, tests, doctor visits) and trimester-wise guidance with walking and exercise sessions.

> **Status:** Phase 0 — discovery & design. No application code yet.

## Principles

1. **Calm by default** — audio-first, few notifications, low screen time.
2. **Safe, not medical** — informs and tracks; never diagnoses.
3. **Private by design** — works without an account; data stays on the device; no ads.
4. **No guilt** — gentle progress, no punishing streaks.
5. **Inclusive** — Garbhasanskar is optional; multilingual; runs well on low-end phones.
