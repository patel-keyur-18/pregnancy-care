# M9b EPUB Books Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** DRM-free `.epub` books import into the library and open in the text reader with chapter headings, a "Chapter n · title" line and a Contents sheet, keeping her place.

**Architecture:** A pure-Dart parser (`lib/features/sessions/domain/epub.dart`) unzips the EPUB with `archive`, reads the OPF, spine and table of contents with `xml`, and turns each spine document into paragraphs. Import runs a quick check (`inspectEpub`) and copies nothing when the file isn't an EPUB or is locked. The reader parses in `compute()` and renders the chapters through the existing text path (whole text laid out, position in thousandths); chapter offsets come from each heading's render box through `RenderAbstractViewport.getOffsetToReveal`.

**Tech Stack:** Flutter (Dart 3.13, `const new(...)` constructors), drift (schema v14), Riverpod 3, go_router, gen-l10n, `archive` 4.3.0, `xml` 7.1.0.

**Spec:** [docs/superpowers/specs/2026-10-11-m9-records-pdf-epub-design.md](../specs/2026-10-11-m9-records-pdf-epub-design.md) §5 (M9b), §6 boards 11–13, §7. Boards approved 2026-10-11: `LibraryAdd` ("A book (PDF, EPUB or text)"), `Reader` with `epub` (Contents button between the title and "Aa"; subtitle "Chapter 6 · The little lamp"), `ReaderContents` (sheet: "Contents", "Evening stories · 8 chapters", numbered Literata rows, min height 52, the current row on `primary-soft` with "Reading" in 12/800 `on-primary-soft`).

## Owner decision this plan asks for

**Schema v14 (no table change).** The spec says M9b needs no schema change, and that an older app reading a backup with an EPUB row is "the usual newer backup" case. That isn't true. The restore refuses a backup only when its `schemaVersion` is higher (`backup_service.dart:184`). A 1.8.0 backup restored on 1.7.0 would therefore go through. Drift would then throw on the unknown `epub` kind, and the library would fail to load. Task 1 bumps `schemaVersion` to 14 with an empty step, so 1.7.0 says "This backup was made by a newer Navmaas". **If you'd rather keep v13, drop Task 1's schema steps (1–4) and the v14 lines in Task 6.**

## Review Focus

1. **Font obfuscation:** a DRM-free EPUB with embedded fonts has a `META-INF/encryption.xml` that uses only the IDPF or Adobe font-obfuscation algorithms. It must import, not be called "locked". Covered by Task 2: `font obfuscation alone is not DRM`.
2. **Chapters split across files, and title pages:** a spine document with no TOC entry and no `h1`–`h3` joins the chapter before it. The first such document becomes a chapter named after the book. Contents never shows a blank row. Covered by Task 2: `an untitled document joins the chapter before it`.
3. **A short last chapter:** its heading can't scroll to the top. Jumping to it must still say "Chapter 3 · …" and mark it "Reading". Covered by Task 4: `Contents jumps to a short last chapter`.
4. **Reopening on a chapter heading:** the place is stored in thousandths, and rounding may land a few pixels above the heading. Reopening must still name that chapter. Covered by Task 4: the widget test reopens on chapter 2.
5. **Entities and non-ASCII text:** `&nbsp;`, `&mdash;`, `&rsquo;`, numeric entities and Devanagari text come through as characters, and a TOC `href` with `%20` and a `#fragment` still names its chapter. Covered by Task 2: `entities and Hindi text are decoded` and `ncx src with a fragment and %20`.

Known ceiling (not fixed here): the reader lays out the whole text at once, which is the existing text path. A novel-length EPUB (about 1 MB of text) may be slow to open. Check this on the phone (Task 6 Step 8). A lazy list would need a different position model, so it would be its own follow-up.

// test/features/sessions/epub_fixture.dart
import 'dart:convert';
import 'dart:typed_data';

import 'package:archive/archive.dart';

const fixtureChapters = [
  ('Morning light', '<h1>Morning light</h1><p>The sun came up.</p>'),
  ('The river path', '<h1>The river path</h1><p>Water ran by.</p>'),
  ('Home', '<h2>Home</h2><p>The lamp was lit.</p>'),
];

String xhtml(String body) =>
    '<?xml version="1.0" encoding="utf-8"?>\n'
    '<!DOCTYPE html>\n'
    '<html xmlns="http://www.w3.org/1999/xhtml" '
    'xmlns:epub="http://www.idpf.org/2007/ops">'
    '<head><title>x</title></head><body>$body</body></html>';

/// A small EPUB built in memory (M9b tests). Chapter files are
/// `OEBPS/text/ch1.xhtml`…; the manifest lists them in reverse so tests
/// see the spine order kept. [toc] false leaves the TOC out. [files] adds
/// or replaces files by path (an `encryption.xml`, a broken chapter).
Uint8List buildEpub({
  String title = 'Evening stories',
  List<(String, String)> chapters = fixtureChapters,
  bool epub3 = true,
  bool toc = true,
  Map<String, String> files = const {},
}) {
  final n = chapters.length;
  final all = <String, String>{
    'mimetype': 'application/epub+zip',
    'META-INF/container.xml':
        '<?xml version="1.0"?><container version="1.0" '
        'xmlns="urn:oasis:names:tc:opendocument:xmlns:container">'
        '<rootfiles><rootfile full-path="OEBPS/content.opf" '
        'media-type="application/oebps-package+xml"/></rootfiles></container>',
    'OEBPS/content.opf':
        '<?xml version="1.0"?><package xmlns="http://www.idpf.org/2007/opf" '
        'version="${epub3 ? '3.0' : '2.0'}">'
        '<metadata xmlns:dc="http://purl.org/dc/elements/1.1/">'
        '<dc:title>$title</dc:title></metadata><manifest>'
        '${[for (var i = n; i >= 1; i--) '<item id="c$i" href="text/ch$i.xhtml" media-type="application/xhtml+xml"/>'].join()}'
        '${toc && epub3 ? '<item id="nav" href="nav.xhtml" properties="nav" media-type="application/xhtml+xml"/>' : ''}'
        '${toc && !epub3 ? '<item id="ncx" href="toc.ncx" media-type="application/x-dtbncx+xml"/>' : ''}'
        '</manifest><spine${toc && !epub3 ? ' toc="ncx"' : ''}>'
        '${[for (var i = 1; i <= n; i++) '<itemref idref="c$i"/>'].join()}'
        '</spine></package>',
    for (final (i, (_, body)) in chapters.indexed)
      'OEBPS/text/ch${i + 1}.xhtml': xhtml(body),
    if (toc && epub3)
      'OEBPS/nav.xhtml': xhtml(
        '<nav epub:type="toc"><ol>'
        '${[for (final (i, (t, _)) in chapters.indexed) if (t.isNotEmpty) '<li><a href="text/ch${i + 1}.xhtml">$t</a></li>'].join()}'
        '</ol></nav>',
      ),
    if (toc && !epub3)
      'OEBPS/toc.ncx':
          '<?xml version="1.0"?><ncx xmlns="http://www.daisy.org/z3986/2005/ncx/" '
          'version="2005-1"><navMap>'
          '${[for (final (i, (t, _)) in chapters.indexed) if (t.isNotEmpty) '<navPoint id="p$i"><navLabel><text>$t</text></navLabel><content src="text/ch${i + 1}.xhtml"/></navPoint>'].join()}'
          '</navMap></ncx>',
    ...files,
  };
  final archive = Archive();
  for (final MapEntry(key: path, value: text) in all.entries) {
    archive.addFile(ArchiveFile.bytes(path, utf8.encode(text)));
  }
  return ZipEncoder().encodeBytes(archive);
}

// lib/features/sessions/domain/epub.dart
import 'dart:convert';
import 'dart:typed_data';

import 'package:archive/archive.dart';
import 'package:path/path.dart' as p;
import 'package:xml/xml.dart';

/// One chapter: its title and paragraphs (a `<br>` is a `\n` inside one).
typedef EpubChapter = ({String title, List<String> paragraphs});

/// A DRM-free EPUB as text (M9b): its own title, if any, and at least one
/// chapter in reading order.
typedef EpubBook = ({String? title, List<EpubChapter> chapters});

enum EpubProblem { unreadable, locked }

class EpubException implements Exception {
  const new(this.problem);

  final EpubProblem problem;

  @override
  String toString() => 'EpubException(${problem.name})';
}

const _unreadable = EpubException(EpubProblem.unreadable);

/// Font obfuscation (IDPF, Adobe) lives in `encryption.xml` too, but the
/// text stays readable: not DRM.
const _fontObfuscation = {
  'http://www.idpf.org/2008/embedding',
  'http://ns.adobe.com/pdf/enc#RC',
};

const _skipped = {
  'head', 'img', 'svg', 'table', 'script', 'style', 'math', 'audio', //
  'video', 'object', 'iframe',
};
const _blocks = {'p', 'li', 'blockquote', 'h1', 'h2', 'h3', 'h4', 'h5', 'h6'};
const _headings = {'h1', 'h2', 'h3'};
const _html = XmlDefaultEntityMapping.html5();

/// The quick check at import: throws [EpubException] when [bytes] isn't a
/// readable EPUB or is locked; otherwise returns the book's title.
String? inspectEpub(Uint8List bytes) => _Package.open(bytes).title;

/// Reads the whole book. Top-level, for `compute()`.
EpubBook parseEpub(Uint8List bytes) {
  final pkg = _Package.open(bytes);
  final titles = pkg.tocTitles();
  final chapters = <EpubChapter>[];
  for (final path in pkg.spine) {
    final source = pkg.text(path);
    if (source == null) continue;
    final (:heading, :paragraphs) = _readXhtml(source);
    final title = titles[path] ?? heading;
    if (title == null) {
      if (chapters.isNotEmpty) {
        chapters.last.paragraphs.addAll(paragraphs);
      } else if (paragraphs.isNotEmpty) {
        chapters.add((title: pkg.title ?? '', paragraphs: paragraphs));
      }
      continue;
    }
    if (paragraphs.isNotEmpty && _same(paragraphs.first, title)) {
      paragraphs.removeAt(0);
    }
    chapters.add((title: title, paragraphs: paragraphs));
  }
  chapters.removeWhere((c) => c.paragraphs.isEmpty);
  if (chapters.isEmpty) throw _unreadable;
  return (title: pkg.title, chapters: chapters);
}

class _Package {
  // Not const: `_manifest` is a late field with an initializer.
  new._(this._archive, this.opfPath, this.opf);

  factory open(Uint8List bytes) {
    final Archive archive;
    try {
      archive = ZipDecoder().decodeBytes(bytes);
    } on Object {
      throw _unreadable;
    }
    String? read(String path) => switch (archive.findFile(path)) {
      final f? => utf8.decode(f.content, allowMalformed: true),
      null => null,
    };
    try {
      if (read('META-INF/encryption.xml') case final enc?) {
        final drm = _all(XmlDocument.parse(enc), 'EncryptionMethod').any(
          (m) => !_fontObfuscation.contains(m.getAttribute('Algorithm')),
        );
        if (drm) throw const EpubException(EpubProblem.locked);
      }
      final container = XmlDocument.parse(read('META-INF/container.xml')!);
      final opfPath = _all(container, 'rootfile').first.getAttribute(
        'full-path',
      )!;
      return _Package._(archive, opfPath, XmlDocument.parse(read(opfPath)!));
    } on EpubException {
      rethrow;
    } on Object {
      throw _unreadable;
    }
  }

  final Archive _archive;
  final String opfPath;
  final XmlDocument opf;

  String? text(String path) => switch (_archive.findFile(path)) {
    final f? => utf8.decode(f.content, allowMalformed: true),
    null => null,
  };

  String? get title => switch (_all(opf, 'title').firstOrNull) {
    final t? when _clean(t.innerText).isNotEmpty => _clean(t.innerText),
    _ => null,
  };

  late final Map<String, XmlElement> _manifest = {
    for (final item in _all(opf, 'item'))
      if (item.getAttribute('id') case final id?) id: item,
  };

  String? _href(XmlElement? item) => switch (item?.getAttribute('href')) {
    final h? => _resolve(opfPath, h),
    null => null,
  };

  /// The spine's documents, in reading order.
  List<String> get spine => [
    for (final ref in _all(opf, 'itemref'))
      if (_href(_manifest[ref.getAttribute('idref')]) case final path?) path,
  ];

  /// Document path → its title in the EPUB 3 nav or the EPUB 2 ncx. Empty
  /// when there's none or it can't be read: headings name the chapters.
  Map<String, String> tocTitles() {
    final titles = <String, String>{};
    void add(String base, String? href, String title) {
      if (href != null && title.isNotEmpty) {
        titles.putIfAbsent(_resolve(base, href), () => title);
      }
    }

    try {
      final nav = _manifest.values
          .where(
            (i) => (i.getAttribute('properties') ?? '').split(' ').contains(
              'nav',
            ),
          )
          .firstOrNull;
      if (_href(nav) case final navPath?) {
        final doc = XmlDocument.parse(text(navPath)!, entityMapping: _html);
        final navs = _all(doc, 'nav');
        final toc =
            navs
                .where(
                  (n) => n.attributes.any(
                    (a) =>
                        a.localName == 'type' &&
                        a.value.split(' ').contains('toc'),
                  ),
                )
                .firstOrNull ??
            navs.firstOrNull;
        for (final a in toc == null ? const <XmlElement>[] : _all(toc, 'a')) {
          add(navPath, a.getAttribute('href'), _clean(_text(a)));
        }
        return titles;
      }
      final ncxId = _all(opf, 'spine').firstOrNull?.getAttribute('toc');
      if (_href(_manifest[ncxId]) case final ncxPath?) {
        final doc = XmlDocument.parse(text(ncxPath)!, entityMapping: _html);
        for (final point in _all(doc, 'navPoint')) {
          add(
            ncxPath,
            _all(point, 'content').firstOrNull?.getAttribute('src'),
            _clean(_all(point, 'text').firstOrNull?.innerText ?? ''),
          );
        }
      }
    } on Object {
      // A broken TOC: headings name the chapters.
    }
    return titles;
  }
}

Iterable<XmlElement> _all(XmlNode node, String localName) =>
    node.descendantElements.where((e) => e.localName == localName);

/// [href] relative to the file at [base], without its `#fragment`.
String _resolve(String base, String href) {
  final path = href.split('#').first;
  String decoded;
  try {
    decoded = Uri.decodeComponent(path);
  } on ArgumentError {
    decoded = path;
  }
  return p.posix.normalize(p.posix.join(p.posix.dirname(base), decoded));
}

/// Paragraphs of one spine document and its first `h1`–`h3`.
({String? heading, List<String> paragraphs}) _readXhtml(String source) {
  final XmlDocument doc;
  try {
    doc = XmlDocument.parse(source, entityMapping: _html);
  } on Object {
    return _stripped(source);
  }
  final body = _all(doc, 'body').firstOrNull ?? doc.rootElement;
  String? heading;
  final paragraphs = <String>[];
  void walk(XmlElement e) {
    for (final child in e.childElements) {
      final name = child.localName.toLowerCase();
      if (_skipped.contains(name)) continue;
      final leaf =
          _blocks.contains(name) &&
          !child.descendantElements.any(
            (d) => _blocks.contains(d.localName.toLowerCase()),
          );
      if (!leaf) {
        walk(child);
        continue;
      }
      final text = _clean(_text(child));
      if (text.isEmpty) continue;
      if (heading == null && _headings.contains(name)) heading = text;
      paragraphs.add(text);
    }
  }

  walk(body);
  // Text only in <div>s: keep it rather than lose the chapter.
  if (paragraphs.isEmpty) return _stripped(source);
  return (heading: heading, paragraphs: paragraphs);
}

/// [node]'s text: source whitespace is one space, `<br>` is `\n`.
String _text(XmlNode node) => switch (node) {
  XmlText(:final value) || XmlCDATA(:final value) => value.replaceAll(
    RegExp(r'\s+'),
    ' ',
  ),
  XmlElement(:final localName) when localName.toLowerCase() == 'br' => '\n',
  XmlElement(:final localName)
      when _skipped.contains(localName.toLowerCase()) =>
    '',
  XmlElement() => node.children.map(_text).join(),
  _ => '',
};

/// Collapses spaces (NBSP too) and trims each line; drops empty lines.
String _clean(String s) => [
  for (final line in s.split('\n'))
    if (line.replaceAll(RegExp(r'\s+'), ' ').trim() case final l
        when l.isNotEmpty)
      l,
].join('\n');

bool _same(String a, String b) => _clean(a).toLowerCase() == _clean(b).toLowerCase();

/// For a document that won't parse: its text with the tags stripped, split
/// into paragraphs at block ends.
({String? heading, List<String> paragraphs}) _stripped(String source) {
  final text = source
      .replaceAll(
        RegExp(
          r'<(head|script|style|svg|table)\b.*?</\1\s*>',
          caseSensitive: false,
          dotAll: true,
        ),
        '',
      )
      .replaceAll(RegExp(r'\s+'), ' ')
      .replaceAll(RegExp(r'<br\s*/?>', caseSensitive: false), '\n')
      .replaceAll(
        RegExp(r'</(p|li|blockquote|h[1-6]|div)\s*>', caseSensitive: false),
        '\n\n',
      )
      .replaceAll(RegExp('<[^>]*>'), '');
  return (
    heading: null,
    paragraphs: [
      for (final block in _html.decode(text).split(RegExp(r'\n\s*\n')))
        if (_clean(block) case final c when c.isNotEmpty) c,
    ],
  );
}

New methods:

```dart
  /// The scroll offset that puts chapter [i]'s heading at the top, capped at
  /// the end (a short last chapter can't reach the top). Computed from the
  /// heading's render box: the text view lays every paragraph out.
  double? _chapterOffset(int i) {
    final box = _chapterKeys[i].currentContext?.findRenderObject();
    if (box == null || !_scroll.hasClients) return null;
    final offset = RenderAbstractViewport.of(box)
        .getOffsetToReveal(box, 0)
        .offset;
    return offset.clamp(0, _scroll.position.maxScrollExtent);
  }

  /// Names the chapter she is in: the last heading at or above the top.
  /// Places are kept in thousandths, so a reopened place may sit up to one
  /// thousandth above the heading it was on.
  void _trackChapter() {
    if (_chapterKeys.isEmpty || !_scroll.hasClients) return;
    final top =
        _scroll.offset + _scroll.position.maxScrollExtent / _textTotal + 1;
    var at = 0;
    for (var i = 0; i < _chapterKeys.length; i++) {
      final offset = _chapterOffset(i);
      if (offset != null && offset <= top) at = i;
    }
    if (at != _chapter) setState(() => _chapter = at);
  }

  Future<void> _contents() async {
    final chapters = _chapters!;
    final picked = await showModalBottomSheet<int>(
      context: context,
      showDragHandle: true,
      isScrollControlled: true,
      builder: (sheet) => _ContentsSheet(
        bookTitle: _item!.title,
        chapters: [for (final c in chapters) c.title],
        current: _chapter,
      ),
    );
    if (picked == null || !mounted) return;
    if (_chapterOffset(picked) case final offset?) _scroll.jumpTo(offset);
    setState(() => _chapter = picked);
  }
```
